Find out which prompt works best

A prompt is the instruction you give an AI. Small changes in wording can change the answers a lot. Here you write a few versions, test them all on the same examples, and see which one gets the most answers right.

1. Write promptsStart from the ready-made versions, or change them.
2. Test themEach prompt answers the same examples.
3. See the winnerEvery answer is checked automatically.

Demo mode. The answers here are simulated, so you can try everything without an AI account. They change when you change the wording of a prompt, but they do not read the text you type.

How do I test with a real AI model?

Pick a task that says real models in the list above. It needs a free API key from Groq. Create a file named .env in the prompt-lab folder with one line, GROQ_API_KEY=your-key, then reload this page. With a real model, the AI reads what you type and writes its own answer.
