prompt-lab

Test a prompt before you ship it

Write prompt variants, try them on one input, then run the whole test set and see which variant passes more cases.

!

Mock models. The models in this experiment are the scripted mock provider. It does not read your input or generate text: it starts from the expected answer and applies the rules in the experiment file, some of which depend on the wording of your prompt. Results show how prompt-lab works. They are not a benchmark. Add a real model to the experiment file to get real answers.
