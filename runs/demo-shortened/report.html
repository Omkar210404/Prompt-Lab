v2_json_rules
Template
Extract fields from the support email below.

Respond with only a JSON object and no other text, with exactly these keys:
- "order_id": the order number, such as "ORD-12345"
- "category": one of "refund", "shipping", "billing", "technical", "account"
- "refund_amount": the amount the customer wants refunded
- "sentiment": one of "negative", "neutral", "positive"

v3_fewshot
Template
Extract fields from the support email below.

Respond with only a JSON object and no other text, with exactly these keys:
- "order_id": the order number, such as "ORD-12345"
- "category": one of "refund", "shipping", "billing", "technical", "account"
- "refund_amount": the amount the customer wants refunded
- "sentiment": one of "negative", "neutral", "positive"

Rules:
- If the email has no order number, use null for order_id.
- If several order numbers appear, use the one the request is about.
- If no refund is requested, use null for refund_amount.
- Use "neutral" when the tone is mixed or the email is a purely factual request.
